Prevendo risco de crédito no Beaumont Bank

Este projeto analisa 682 empréstimos de um banco real (dados anonimizados) e treina um modelo que prevê, antes do contrato ser fechado, se um empréstimo tem risco de inadimplência. Os números abaixo e o simulador são o resultado desse trabalho — nada aqui precisa ser instalado, é só rolar a página.

—Total emprestado (CZK)
—Ticket médio

Teste o modelo você mesmo

Preencha um empréstimo hipotético. O cálculo abaixo roda a mesma árvore de decisão treinada no projeto — só que direto aqui na página, sem precisar do Python.

O modelo foi treinado com apenas duas variáveis de entrada diretamente controláveis (valor e prazo) mais dados da conta; por isso a classificação é uma estimativa didática, não uma decisão de crédito real.

Sobre o projeto: construído com Python, Scikit-Learn, SQL e Streamlit, com deploy pronto para Google Cloud Run. Veja o código-fonte completo, a análise exploratória e o passo a passo de como rodar tudo no repositório.
