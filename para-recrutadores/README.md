# Para quem não é da área técnica

Se você não usa Python nem quer instalar nada só para ver o projeto funcionando,
abra o arquivo **`demo.html`** desta pasta com dois cliques — ele abre no seu
navegador normal (Chrome, Edge, Firefox) e já mostra:

- Os números principais da carteira analisada (total emprestado, ticket médio, taxa de inadimplência)
- Os gráficos reais gerados a partir dos dados
- Um simulador: você digita o valor e o prazo de um empréstimo e vê, na hora,
  como o modelo treinado classificaria o risco daquele contrato

Não precisa de internet, Python, ou qualquer instalação — é uma página só,
autossuficiente.

Para quem quiser entender o projeto todo com mais profundidade técnica
(como o modelo foi treinado, o banco de dados, etc.), o `README.md` principal,
na pasta de cima, tem todos os detalhes.
